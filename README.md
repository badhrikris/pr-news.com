# The Hindu Website Clone

A responsive clone of The Hindu news website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design matching The Hindu's aesthetic
- **Interactive Navigation**: Sticky header with smooth scrolling
- **Multiple Sections**: 
  - Featured articles
  - Latest news
  - Editorials
  - Videos
  - Top picks
  - Opinion pieces
  - Explainer articles
- **Mobile Menu**: Hamburger menu for mobile devices
- **Search Functionality**: Search bar in the header

## File Structure

```
hindu-clone/
├── index.html      # Main HTML structure
├── styles.css      # All styling and responsive design
├── script.js       # Interactive features and functionality
└── README.md       # This file
```

## How to Use

1. Simply open `index.html` in your web browser
2. No build process or dependencies required - it's pure HTML/CSS/JS
3. The website is fully functional and responsive

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Customization

You can easily customize:
- Colors: Edit CSS variables in `styles.css` (root section)
- Content: Modify the HTML in `index.html`
- Functionality: Add features in `script.js`
